# DT Money

Aplicação de controle financeiro desenvolvida com React, TypeScript e Vite, com controle de receitas e despesas, resumo de saldo e busca de transações. Desenvolvido durante o curso Ignite da Rocketseat.

## Tecnologias

- [React](https://react.dev/) — biblioteca para construção de interfaces
- [TypeScript](https://www.typescriptlang.org/) — tipagem estática
- [Vite](https://vitejs.dev/) — bundler e servidor de desenvolvimento
